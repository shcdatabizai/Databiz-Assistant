# 오뚜기 데이터 제안서 생성기

python-pptx로 신한카드 디자인 제안서를 코드로 만든다. 디자인 시스템을 분리해 두어
다른 제안서를 만들 때도 `shinhan_deck.py`만 가져다 쓰면 된다.

```
ottogi_deck/
├── shinhan_deck.py          디자인 시스템 (색/좌표/헬퍼) — 재사용 대상
├── build_ottogi_deck.py     오뚜기 제안서 9장 조립 (DATA 섹션 + page_XX 함수)
├── assets/                  로고, 설문 예시 이미지
├── data/                    대표성 분석용 CSV
└── build/                   결과물
```

## 실행

```bash
pip install python-pptx pandas numpy lxml
python build_ottogi_deck.py                                   # 9장
python build_ottogi_deck.py --merge 원본.pptx                  # 원본 2장 삽입 → 11장
python build_ottogi_deck.py --merge 원본.pptx --merge-at 4,-1  # 삽입 위치 지정
```

원신한 폰트(OneShinhanBold / OneShinhanMedium)를 PC에 설치해야 의도한 서체로 보인다.
미설치 시 기본 고딕으로 대체된다.

## 좌표계

슬라이드를 **680 × 383 단위**로 잡고 `I()`로 인치(EMU) 환산한다. 16:9 기준이다.
`txt()`의 `y`는 텍스트 **기준선(baseline)**이다. 박스 상단이 아니다.

```
  0 ~  44   헤더 바 (번호 / 분모 / 제목 / 로고)
 56 ~  98   헤드 메시지 (14px 굵게 + 11px 보조)
116          섹션 라벨 ①②③
116 ~ 350   본문
360 ~ 378   주석
좌우 여백 28 · 2단 구성은 좌 28~330 / 우 352~652
```

## 자주 쓰는 헬퍼

| 함수 | 용도 |
|---|---|
| `frame(sl, "03", "07", "제목")` | 헤더 바 + 페이지 번호 + 로고 |
| `head(sl, 메인, 보조)` | 헤드 메시지 2행 |
| `sec(sl, x, x_end, y, "① 라벨")` | 섹션 라벨 + 밑줄 |
| `txt(sl, x, y, text, size, color, bold, align, w)` | 텍스트 (align: l/r/c) |
| `rect / bar / dot / hline / seg / polyline` | 도형 |
| `illu_block(...)` + `stamp(...)` | 예시 수치 영역 (분홍 점선 + ILLUSTRATIVE 도장) |
| `cover(...)` / `toc(...)` | 표지 / 목차 |

## 작성 규칙

- **헤드 메시지 1행은 14px 기준 40자 이내.** 넘으면 줄바꿈되어 보조문과 겹친다.
- **주석은 10px 기준 60자 이내.** 넘치면 두 줄이 되어 아래 줄과 겹친다.
- 한글은 폰트 크기와 글자 폭이 거의 1:1이다. `w`를 정할 때 `글자수 × 폰트크기 × 1.15`로 잡으면 안전하다.
- 실측 데이터는 흰 배경, 추정·예시 수치는 `illu_block` + `stamp`로 반드시 구분한다.
- 막대 길이는 데이터에 비례하도록 직접 계산해 둔다. 값만 바꾸고 길이를 안 바꾸면 거짓말이 된다.
- 텍스트 겹침은 렌더링 전에는 안 보인다. 수정 후 PDF로 변환해 눈으로 확인한다.

## 수정 방법

- **숫자만 바꾸기** → `build_ottogi_deck.py` 상단 `DATA` 섹션
- **색·간격 바꾸기** → `shinhan_deck.py`의 `C` 딕셔너리와 `frame/head/sec`
- **페이지 추가** → `page_XX` 함수를 하나 더 만들고 `main()`에서 호출, `TOTAL`과 `TOC_ITEMS` 갱신
- **페이지 순서 변경** → `main()`의 호출 순서만 바꾸고 `frame()`의 번호 인자 수정

## 페이지 구성

| 페이지 | 내용 |
|---|---|
| 표지 | 네이비 전면 · 국문 로고 · 발행 정보 |
| 목차 | 7개 항목 |
| 01 데이터 개요 | 대표성 요약 카드 + 통계청 대비 금액 추이 2종 |
| 02 온라인 커머스 브랜드 분석 | 구매 MS · 성/연령 데모 표 · 라이프스테이지 누적 막대 |
| 03 온라인 시장 분석 | 플랫폼별 셀러수/거래액 이중 막대 + 입점·매출 통합표 |
| 04 유통 채널 분석 | 채널 비중 도넛 + 식품 특화 채널 + 연령×성별 그리드 |
| 05 B2B 외식업 상권 분석 | 외식 업종 비중 + 제품군 세그먼트 + 상권 지표 |
| 06 글로벌 잠재 고객 분석 | 국적별 비중 + 점포별 구성 + 결제 단가 |
| 07 정밀 타겟 서베이 | 서베이 개요 + 설문지·결과표 이미지 |

## 원본 슬라이드 병합

`merge_slides()`는 다른 pptx의 슬라이드를 도형·이미지·서식까지 그대로 복사한다.
이미지는 파트명 충돌을 피하려고 새 파트로 등록한다. 이 처리를 빼면 저장은 되지만
PowerPoint에서 파일이 열리지 않는다.

```python
merge_slides("out.pptx", "원본.pptx", {0: 4, 1: 10})   # 원본 1번→5번째, 2번→11번째
```

## 알려진 제약

- 도넛 차트는 네이티브 차트라 `has_title = False`와 `holeSize` 조정이 필요하다. 빼면 제목이 붙고 도넛이 작아진다.
- `txt()`는 고정 높이 박스라 자동 줄바꿈이 되면 위아래로 넘친다. 긴 문장은 직접 두 줄로 나눈다.
- LibreOffice 렌더링은 한글 자간이 PowerPoint보다 넓게 나온다. 여유를 두고 폭을 잡는다.
